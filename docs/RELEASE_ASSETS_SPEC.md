# Vone Trucking - Release Assets Specification

## Overview

This document specifies all assets required for releasing the Vone Trucking mobile application on Google Play Store (Android) and Apple App Store (iOS).

## 1. App Icon Requirements

### Android (Google Play)

**Adaptive Icon** (Required)
- **Size**: 512 x 512 px
- **Format**: PNG (32-bit)
- **Color Space**: sRGB
- **Layers**: Foreground and background layers
- **Safe Zone**: Keep important content within 264 x 264 px center circle
- **File**: `android-adaptive-icon.png`

**Legacy Icon** (Optional but recommended)
- **Size**: 512 x 512 px
- **Format**: PNG (32-bit)
- **Shape**: Square with rounded corners (optional)
- **File**: `android-legacy-icon.png`

### iOS (App Store)

**App Icon**
- **Size**: 1024 x 1024 px
- **Format**: PNG (no alpha channel)
- **Color Space**: sRGB or P3
- **Corner Radius**: Applied automatically by iOS
- **File**: `ios-app-icon.png`

### Design Specifications

**Vone Trucking Icon Concept**:
- **Primary Color**: Deep blue (#0047AB) representing trust and reliability
- **Accent Color**: Orange (#FF6600) representing energy and movement
- **Symbol**: Stylized truck icon with location pin or road element
- **Typography**: "VONE" in bold, modern sans-serif font
- **Style**: Flat design, professional, easily recognizable at small sizes

**Design Elements**:
- Truck silhouette (simplified, side view)
- GPS/location pin integrated into design
- Optional: Road/highway element
- Clean, minimal design that works at all sizes

### Icon Sizes for App (Auto-generated by Expo)

Android:
- 48x48, 72x72, 96x96, 144x144, 192x192 (mdpi, hdpi, xhdpi, xxhdpi, xxxhdpi)

iOS:
- 20x20, 29x29, 40x40, 60x60, 76x76, 83.5x83.5, 1024x1024

## 6. Data Safety Disclosures

### Android (Google Play Data Safety Section)

**Data Collection**:
- ✅ Location data (precise location) - Required for trip tracking
- ✅ Photos and videos - Optional for proof of delivery
- ✅ Personal info (name, email, phone) - Required for user accounts
- ✅ Financial info (expense records) - Required for trip management
- ✅ App activity (trip history) - Required for analytics

**Data Usage**:
- App functionality (core features)
- Analytics (performance monitoring)

**Data Sharing**:
- No third-party sharing
- All data stays within user's organization

**Security Practices**:
- Data encrypted in transit (HTTPS/TLS)
- Data encrypted at rest
- User can request data deletion
- Follows data security best practices

### iOS (App Privacy Section)

**Data Linked to User**:
- Location (precise)
- User content (photos, trip data)
- Identifiers (user ID)
- Usage data (app interactions)

**Data Not Linked to User**:
- Diagnostics (crash reports, performance data)

**Tracking**:
- This app does not track you across other apps
